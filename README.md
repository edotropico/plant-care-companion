# 🌿 Plant Care PWA

> An elegant, lightweight Progressive Web App designed for the daily care of indoor plants, built with a strong focus on UI/UX and practicality.

![Dark Theme](https://img.shields.io/badge/Theme-Dark%20%2316241F-green)
![PWA Ready](https://img.shields.io/badge/PWA-Ready-blue)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

## ✨ Key Features
* **Minimal & Dark Mode Design:** A relaxing interface designed to be used comfortably even in low-light environments.
* **100% Offline-First:** Thanks to PWA technology, you can check plant profiles and log care routines even without an internet connection.
* **Smart Management:** Track waterings, health status, and reminders without unnecessary clutter.
* **Installable:** Add it straight to your smartphone's home screen like a native app on both Android and iOS.
